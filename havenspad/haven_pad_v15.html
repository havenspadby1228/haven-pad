📖 How to Get a Google OAuth Client ID
Follow these steps once. It's free and takes about 5 minutes.
1Go to Google Cloud Console
https://console.cloud.google.com
Create a new project (e.g. "Haven Pad")
2Enable Google Calendar API
APIs & Services → Library → Search "Google Calendar API" → Enable
3Configure OAuth Consent Screen
APIs & Services → OAuth consent screen → External → Fill name & email. Add scope: https://www.googleapis.com/auth/calendar
4Create OAuth 2.0 Client ID
Credentials → Create Credentials → OAuth Client ID → Web Application. Add your current page URL (or http://localhost for local use) as an Authorized JavaScript Origin.
5Copy the Client ID
Copy the string ending in .apps.googleusercontent.com and paste it in the field on the Google Calendar page.
