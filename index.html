Google Sheet sync

Pull replaces this app's guest list with what's in your Google Sheet. Push writes the app's bookings into the sheet — it matches rows by Booking Number, updating existing rows and appending new ones (it never deletes sheet rows). If you edited bookings here, push before you pull.

One-time setup: open your spreadsheet → Extensions → Apps Script → paste the HavenPad_Sheet_Sync.gs code → set SHEET_NAME to your tab name → Deploy → New deployment → Web app → Execute as Me, access Anyone with the link → copy the /exec URL here. To protect your data, also set ACCESS_KEY at the top of the script (e.g. 'haven2026'), redeploy a New version, and enter the same key above — every device will be asked for it once.
